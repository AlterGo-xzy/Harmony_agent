# OpenHarmony Development Skill

Single-skill package for practical OpenHarmony/HarmonyOS development in ChatGPT and Codex, including Windows/DevEco/Hvigor projects.

The top-level `SKILL.md` is the only installed skill definition. Nested `WORKFLOW.md` files are supporting references. Optional upstream wrappers and omitted scripts are not required: the skill uses the project's native toolchain and reports unavailable checks honestly.

The bundled Windows development reference explains how to discover the active project's modules, SDK, and Hvigor tasks. Re-read the target project's profiles before every build instead of carrying assumptions between projects.
